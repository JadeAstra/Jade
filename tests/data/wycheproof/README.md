https://github.com/C2SP/wycheproof, directory `testvectors_v1`, at commit
65ca494727a52944c204441c860b039e6786b99b (downloaded 2026-11-20).

WinterWolf. Its text is in the `LICENSE` file at the root of this repository,
and at https://www.apache.org/licenses/LICENSE-2.0. The Wycheproof project
has no NOTICE file.

They are used only by the tests (`tests/crypto_vectors.ww`) and are not part
of ww.exe.
